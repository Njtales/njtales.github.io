S&P 500 Data Pipeline

Practice project

An Airflow ETL exercise using Yahoo Finance price data for a selected list of S&P 500 companies.

Flow
Download prices → save CSV → clean and calculate metrics → load PostgreSQL with SQLAlchemy.
Processing
Removes missing and duplicate rows, then calculates daily returns and 5- and 20-period moving averages.
Learning focus
Task dependencies, retry configuration and the trade-offs of CSV handoffs and full-table replacement loads.

Airflow · Python · pandas · PostgreSQL · Docker

PostgreSQL Data Warehouse

Practice · in progress

A local Airflow and PostgreSQL exercise using Instacart CSV datasets, with pgAdmin for database inspection.

Source
The DAG defines tables for aisles, products, departments, orders and order-product datasets, followed by CSV load tasks.
Learning focus
Relational schemas, PostgreSQL COPY-based loading and explicit extraction → table creation → loading dependencies.
Status
